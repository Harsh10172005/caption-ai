Questions creators ask

Does my video leave my device?

Only to be captioned. When you upload a video, it is sent to the Caption AI server, which transcribes it and — for the captioned MP4 export — burns the captions in. Editing, styling and SRT downloads all happen in your browser. If you use your own API key in Advanced options, the file goes to that provider instead.

Why Roman script for Hinglish?

Most short-form captions in India are read in Roman script because that's how people type and chat every day. Roman Hinglish keeps the mix of Hindi and English natural and easy to scan on a phone.

What if the transcription makes a mistake?

It will, sometimes — especially with names, slang, or fast speech. That's why every cue is editable. Click a caption, fix the words, and the preview and exports update instantly.

Why is the API-key mode limited to 25 MB?

That's OpenAI's upload limit for its transcription endpoint. The main automatic flow has no such problem — the caption server accepts videos up to 300 MB.

What format is the exported video?

The main download is a real MP4 with captions burned in by the server, ready for Instagram/YouTube. There's also a browser export that produces a WebM in Chrome (renders in real time), plus SRT caption files.

How does automatic captioning work without an API key?

The Caption AI server runs Whisper on itself. Your video is uploaded to that server, transcribed there, and the captions come back to this editor — no key and no pasting scripts. The app finds the server automatically; you never have to type an address.

Do you store my API key?

No. Your key lives only in the page's memory while the tab is open. Refresh the page and it's gone. It is never written to localStorage, cookies, or any server by this app.
