Questions creators ask

Does my video leave my device?

Not by default. The editor, styling, and video export all run locally in your browser. Only if you press “Transcribe with Whisper” is the file sent to OpenAI using your own key.

Why Roman script for Hinglish?

Most short-form captions in India are read in Roman script because that's how people type and chat every day. Roman Hinglish keeps the mix of Hindi and English natural and easy to scan on a phone.

What if the transcription makes a mistake?

It will, sometimes — especially with names, slang, or fast speech. That's why every cue is editable. Click a caption, fix the words, and the preview and exports update instantly.

Why is Whisper limited to 25 MB?

That's OpenAI's upload limit for the transcription endpoint. For longer videos, compress the clip, trim it, or paste a script instead — script mode has no size limit.

What format is the exported video?

The browser export produces a WebM file with captions burned in, which plays in Chrome and uploads to most platforms. If you need MP4, convert the WebM with any free converter, or use the SRT files in your main editor.

Do you store my API key?

No. Your key lives only in the page's memory while the tab is open. Refresh the page and it's gone. It is never written to localStorage, cookies, or any server by this app.
